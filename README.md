# tieng-viet: how the folder works

Mike's Saigon Vietnamese course. Since 1 October 2026 it runs as an app at the site root,
https://deutschmitmike.github.io/tieng-viet/ . Everything in it comes out of `sentences.csv` (every sentence
ever written, one per row) and the lesson files in `lessons/`.

## Layout

```
plan.md                  master plan: the 50 lessons, fixed decisions, audio
WEEKLY.md                how the next lesson is built
CLAUDE.md                the rules that must never be got wrong
sentences.csv            id|vi|tts|pron_note|hanzi|en|zh|tags
lessons/lNN.md           one lesson: ids, introduction pages, tandem task (lesson 1 also has a `drills:` reference line and `start: schedule`)
words.csv                the vocabulary met so far (created when lesson 2 is built)
audio/sentences/         one mp3 per sentence id, generated once, reused forever
voices.json              ElevenLabs voice and settings (decided, do not edit)
app/                     the app: core.js, ui.js, shell.html, build.py, pull_checkin.py, tests/, README.md
index.html, version.json the built app (generated by app/build.py, do not edit)
BUILD                    the app version, YYYY-MM-DD-N
checkin.md               the Friday check-ins, local only (raw tandem messages, the repo is public)
scripts/                 generate_audio.py, common.py, .env (the key, never committed), plus the retired booklet scripts (archive)
schedule.csv, weeks/     the week-1 booklet from before the app, kept as an archive; build.py still reads lesson 1's start days from schedule.csv, so never delete it
```

## One-time setup

1. Python 3 from macOS is enough, no packages. Node for the app tests.
2. `scripts/.env` holds the ElevenLabs key (template: `scripts/.env.example`).

## The repo and the published version

The key never goes in. `scripts/.env` is listed in `.gitignore`, together with `*.env`. If it ever lands in a
commit, the key has to be replaced at ElevenLabs, so check `git status` before every push and never use
`git add -f` on it. `checkin.md` stays out too.

In the repo: the sources, the per-sentence mp3s, the lesson files, the app sources and the built
`index.html` and `version.json`. GitHub Pages serves the root of the main branch.

## The `tts` column

Normally empty. The Saigon respelling (d and gi become y at the start of a syllable) runs automatically in
`scripts/common.py`. Only if the voice still says a word wrong, write the spelling that makes it right into
`tts` for that one sentence; the app always shows the correct `vi`.
